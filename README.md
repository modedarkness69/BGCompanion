# BG Companion

**made by modedarkness**

Помощник для **Hearthstone Battlegrounds**: подсказка при выборе героя, темп таверны, личная статистика и история игр. Бесплатно и с открытым кодом.

## Возможности

- **Выбор героя.** Поверх игры показывается, как вы играли на каждом из предложенных героев (игры, среднее место, топ-4), и отмечается лучший вариант.
- **Темп таверны.** Подсказывает, когда пора повышать тир: по вашим лучшим играм или по стандартной кривой.
- **Статистика героев.** Сколько раз героя предлагали, как часто вы его берёте, среднее место, топ-4, победы.
- **История игр.** Герой, место, тир таверны, на каких ходах вы повышались, кого предлагали.
- **Запись выборов.** Аксессуары, Тёмные дары и открытия: что предлагали и что вы взяли.
- **Актуальная база.** При запуске программа скачивает свежую базу карт ([HearthstoneJSON](https://hearthstonejson.com)) и общую статистику проекта.
- **Автообновление.** Новая версия ставится одной кнопкой.
- **Демо-режим.** Кнопка «Демо: проиграть прошлую игру» показывает оверлей на вашей записанной игре — можно посмотреть, как всё работает, не заходя в матч.

## Установка

1. Откройте [последний релиз](https://github.com/modedarkness69/BGCompanion/releases/latest).
2. Скачайте `BGCompanion-win-x64.zip` и распакуйте в любую папку, например `Документы\BGCompanion`.
3. Запустите `BGCompanion.exe`.

Можно скачать только `Updater.exe`, положить его в пустую папку и запустить: он сам скачает и установит программу.

Ставить .NET не нужно, всё уже внутри.

> **Windows может предупредить «Система Windows защитила ваш компьютер».** Программа не подписана платным сертификатом, поэтому SmartScreen её не знает. Нажмите «Подробнее» → «Выполнить в любом случае». Весь код открыт в этом репозитории.

## Обновление

- Когда выходит новая версия, в программе появляется кнопка **«Обновить»**.
- Или просто запустите `Updater.exe` в папке программы.

Апдейтер сам скачает новую версию с GitHub, заменит файлы и перезапустит программу. Ваша статистика при этом сохраняется: она лежит отдельно, в `%LOCALAPPDATA%\BGCompanion`.

## Как это работает

Программа читает только лог-файлы, которые Hearthstone сам пишет на диск (`Power.log`). В память и файлы игры она не вмешивается и ничего не нажимает за вас. Если запись логов в игре выключена, программа включит её в `log.config`, после этого игру нужно перезапустить один раз.

При первом запуске программа импортирует ваши прошлые игры из старых логов.

## Статистика

- **Личная** собирается из ваших игр и хранится только у вас.
- **Общая** — файл [`data/hero-stats.json`](data/hero-stats.json) в этом репозитории, программа скачивает его при запуске. Пока он пустой, подсказки строятся на личной статистике.

## Для разработчиков

```powershell
dotnet build                      # сборка
dotnet run --project src/BGCompanion
dotnet run --project tools/LogCheck -- "C:\Program Files (x86)\Hearthstone"   # проверка парсера на ваших логах
.\build.ps1                       # релизная сборка в dist\
```

Новая версия: поменять `<Version>` в `Directory.Build.props`, закоммитить, поставить тег `vX.Y.Z` и запушить его. GitHub Actions соберёт программу и опубликует релиз, а апдейтеры пользователей его подхватят.

| Папка | Что внутри |
|---|---|
| `src/BGCompanion.Core` | разбор логов, база карт, статистика, советы, проверка обновлений |
| `src/BGCompanion` | программа (WPF): главное окно и оверлей |
| `src/Updater` | апдейтер и установщик |
| `tools/LogCheck` | проверка парсера на реальных логах |
